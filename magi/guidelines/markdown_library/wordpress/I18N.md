# Internationalization

All user-facing strings pass through translation functions:

| Function | Use |
|:---------|:----|
| `__()` | Strings |
| `_e()` | Echoed strings |
| `_x()` | Context disambiguation |
| `_n()` | Plurals |
| `esc_html__()` / `esc_attr__()` | Translated-and-escaped output |

The text domain matches the plugin slug. Load via `load_plugin_textdomain()` in `init`. **WordPress 6.5+ supports PHP-based translation files** for performance over `.mo`/`.po`.
