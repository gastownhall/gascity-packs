# Compliance and Governance

### Certification Requirements

| Standard | Requirement |
|:---------|:------------|
| SOC 2 | Audit logging, access control, encryption |
| PCI-DSS | Key rotation, network isolation, audit trails |
| HIPAA | Encryption at rest/transit, access logging |
| GDPR | Data residency, right to deletion, audit logs |

### Audit Requirements

- All configuration changes logged with identity
- All secret access logged with timestamp
- Logs retained for **minimum 90 days**
- Quarterly access review documentation
