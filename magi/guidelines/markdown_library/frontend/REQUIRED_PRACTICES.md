# Required Practices

### Always Do

- Define explicit types for all props, state, and function parameters.
- Use strict TypeScript mode.
- Handle loading, error, and empty states explicitly.
- Validate all user input with Zod.
- Validate all API responses at the boundary with Zod.
- Use TanStack Query for server state.
- Memoize expensive computations.
- Lazy load route components.
- Test critical paths with E2E tests.
- Maintain 90%+ test coverage (branches, functions, lines, statements).
- Use semantic HTML.
- Ensure keyboard accessibility.
- Provide meaningful alt text.
- Keep components focused and single-purpose.
- Extract reusable logic to custom hooks.
- Use centralized theme configuration.
- Follow consistent import order.
- Format code with Prettier before commit.
- Use Error Boundaries for error handling at app and feature levels.
- Implement proper focus management.
- Use path aliases for imports.
- Run a shakedown after every production-build-affecting change.
