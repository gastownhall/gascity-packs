# .utilities/ Contract

### Absolute Prohibitions
No project names, application names, repository names, hostnames, or environment-specific paths. Ever.

### Stability Requirements
- No function signature changes.
- No removed exports.
- No silent behavior changes.
- All changes additive.

### On Modification
Read the entire file, verify compliance, correct all violations — even unrelated ones.

### Export Documentation
All exported functions documented in header, snake_case named, single responsibility.
