# Launchers

| Constraint | Detail |
|:-----------|:-------|
| Minimum version | 8.3 Gateways require 1.3.0+ launchers. Bundled by default; backward compatible with 8.1 Gateways |
| DeepLinks / File Associations | NEW in 1.3.0 launchers — **NOT backward compatible** (work against 8.1 only in compatibility mode) |
| Windows Shell Extension | Optional Explorer Shell Extension DLL on Windows for custom file association icons (configured via Project Properties → Launch Icon) |
| URI allow-list | Workstation config gains `allow.uri.schemes` property — explicit allow-list of URI schemes the host OS may open. Pre-seeded with Designer, Vision, Perspective |
