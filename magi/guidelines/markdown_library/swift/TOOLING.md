# Tooling

### SwiftFormat

- Configure via `.swiftformat` at project root.
- Run as **pre-commit hook or CI gate** — not optional.

### SwiftLint

- Configure via `.swiftlint.yml` at project root.
- Run as **pre-commit hook or CI gate** — not optional.

### Xcode Project Settings

- Enable all warnings.
- Set Swift Language Version explicitly.
- Use `-O` for release, `-Onone` for debug.
