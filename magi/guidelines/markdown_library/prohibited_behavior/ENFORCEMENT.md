# Enforcement

| Trigger | Consequence |
|:--------|:------------|
| Single violation | Work rejected; must redo |
| Repeated violation | Escalation to user |
| Pattern violation | Fundamental retraining required |

**Monitoring:** Every code submission is checked against all 29 rules. Automated validation runs where possible. Manual review covers subjective rules.

**Violation handling:**
- Immediate rejection of the work.
- Restart from beginning.
- No partial credit for partial compliance.
