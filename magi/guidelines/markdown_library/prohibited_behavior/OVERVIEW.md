# Prohibited Behavior Library

This directory contains an expanded, modularized version of the Prohibited Behavior contract — 23 core rules + 6 shakedown rules. These rules form an **ABSOLUTE CONTRACT**. They are NOT suggestions, NOT recommendations, NOT guidelines — they are MANDATORY RULES with ZERO EXCEPTIONS. Violation of ANY rule results in IMMEDIATE REJECTION of the work.

## Critical Mandates (Read First)
- **29 total rules** — 23 core rules + 6 shakedown rules. ALL ARE **NOT** SUGGESTIONS. THEY ARE **RULES**.
- **No partial compliance** — FULL COMPLIANCE or FAILURE.
- **Single violation** triggers rejection of the work; restart from the beginning.
