# Cross-Reference and Navigation

### Internal References
When topics relate across sections:
- Name the related section explicitly
- Explain why the reader might need to reference it
- Do not duplicate content
### External References
When external documentation is authoritative (official docs, RFCs, specifications):
- Reference them by name
- Do not attempt to replicate their content
- State what the reader should look for in the external source
