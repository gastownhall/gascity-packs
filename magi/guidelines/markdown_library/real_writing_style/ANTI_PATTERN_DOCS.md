# Anti-Pattern Documentation

### Dedicated Anti-Pattern Sections
Each major topic area should include an explicit "Anti-Patterns" or "Avoid When" section. These sections:
1. Name the anti-pattern specifically
2. Explain why it seems attractive (or how people arrive at it accidentally)
3. Describe the concrete negative consequences
4. Provide the correct alternative
### Inline Prohibitions
Beyond dedicated sections, prohibitions appear inline when discussing specific techniques. Use consistent formatting:
- "Never use..."
- "Prohibited: ..."
- "This is not acceptable because..."
