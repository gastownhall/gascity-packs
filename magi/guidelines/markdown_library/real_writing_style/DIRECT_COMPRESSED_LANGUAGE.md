# Direct, Compressed Language with Zero Fluff

- No Flowery Language, Ever: Avoid metaphors, analogies, and emotional flourishes like the plague. If a sentence doesn't directly convey technical meaning, it doesn't belong. "Robust validation system" is tolerable; "elegantly crafted validator" gets cut.
- Aggressive Use of Active Voice: Everything should read like a command or a log entry. "System caches invalidated entries" > "Invalidated entries are cached by the system."
- Lean on Nouns and Verbs: Use strong, unambiguous terms that do the heavy lifting. Avoid stacking on pointless descriptors. If a term needs ten qualifiers, it's the wrong term.
- Short, Declarative Sentences: Say the thing. Then move on. Compound thoughts are fine, but only if every clause earns its keep. Every sentence should either clarify, instruct, or solve. If it doesn't, delete it.
