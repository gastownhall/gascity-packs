# Tables and Quick Reference

### When to Use Tables
Tables serve two purposes:
1. **Comparison**: When readers need to choose between options (technologies, approaches, configurations)
2. **Reference**: When readers need to look up specific values (naming conventions, limits, defaults)
### Table Requirements
- Every table must have a clear header row
- Column headers must be unambiguous
- Data cells must be complete (no "see above" or blank cells that require inference)
- Tables over 10 rows need either grouping or a different format
### Summary Tables
Each major Part should include at least one summary table that condenses the key decisions or standards for quick scanning. These tables don't replace the detailed explanations — they provide a map to them.
