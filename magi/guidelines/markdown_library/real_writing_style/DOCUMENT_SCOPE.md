# Document Scope and Intent

Guideline documents exist to eliminate ambiguity and provide definitive answers. They replace tribal knowledge, scattered documentation, and "ask the senior dev" patterns with a single authoritative source.
- **Primary objective**: A developer encountering a question within the document's domain should find the answer without external research or clarification.
- **Secondary objective**: The document should make incorrect approaches obvious and correct approaches unambiguous.
- **Tertiary objective**: The document should transfer expert judgment so readers can apply principles to novel situations not explicitly covered.
