# Replication Intent

1. A properly constructed guideline document enables any competent author to produce equivalent documentation for adjacent domains. The structure, depth, and style patterns should be so clear that "write a guideline document about X" produces consistent, high-quality results without additional specification.
2. The goal is not uniformity for its own sake — the goal is eliminating variance that wastes reader attention. When every guideline document follows the same structural patterns, readers know where to find information. They can skim to the relevant section, trust that anti-patterns are documented, and rely on summary tables for quick reference.
---
**Apply this guideline structure to all technical documentation intended to serve as authoritative reference for implementation decisions.**
