# Decision Frameworks

### Decision Trees
For complex choices with multiple factors, provide explicit decision trees:
```
Is [condition A]?
├── Yes: Is [condition B]?
│   ├── Yes → [Recommendation 1]
│   └── No → [Recommendation 2]
└── No: [Recommendation 3]
```
Decision trees must be exhaustive — every path terminates in a clear recommendation.
### Guideline Patterns
- For processes with multiple required steps, provide numbered guideline patterns (not checklists):
    - Step 1: [Action]
    - Step 2: [Action]
    - Step 3: [Verification]
- Guideline Patterns must include verification steps, not just actions.
