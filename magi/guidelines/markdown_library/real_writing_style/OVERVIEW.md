# REAL Writing Style Library

This directory contains an expanded, modularized version of the REAL Writing Style and Guideline Writing Style standards. These standards apply to all technical documentation, design specs, architectural briefs, and authoritative guideline documents.

## Critical Mandates (Read First)
- **No fluff, no filler, no hedge words** — every sentence justifies its presence.
- **Active voice, declarative tone** — read like a command or a log entry.
- **Guideline documents follow the structural contract** — Core Principles, Parts, Style Summary, minimum 1,500 lines.
