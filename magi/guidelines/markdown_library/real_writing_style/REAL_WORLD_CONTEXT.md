# Real-World Context

### Operational Considerations
Enterprise guidelines must address operational reality:
- **Cost implications**: What are the resource costs of different approaches?
- **Scaling boundaries**: At what point does this approach stop working?
- **Failure modes**: What happens when this breaks, and how do you detect it?
- **Team expertise**: What skill level does this require to operate safely?
### Trade-off Acknowledgment
Technical decisions involve trade-offs. When presenting recommendations:
- State what you're optimizing for
- Acknowledge what you're trading away
- Specify when the trade-off calculus changes
