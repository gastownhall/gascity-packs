# Document Maintenance

### Version Awareness
Guidelines must acknowledge that technologies evolve:
- State version numbers when behavior is version-dependent
- Note deprecation status for older approaches
- Indicate review dates for time-sensitive recommendations
### Ownership
Every guideline document should be owned by an identifiable team or role responsible for:
- Accuracy maintenance
- Responding to questions and edge cases
- Incorporating lessons from production incidents
