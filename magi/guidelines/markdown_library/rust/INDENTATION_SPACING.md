# Indentation and Spacing

### Indentation
- **4 spaces** for each indentation level
- Never use tabs

### Spacing
- Single blank line between functions
- Single blank line between import groups
- No unnecessary blank lines within functions
- Minimize vertical space while maintaining readability

### Braces
- Opening brace `{` on same line as declaration
- Closing brace `}` on its own line for multi-line blocks
- Exception: Single-line blocks when entire scope fits

### Operator Spacing
```rust
let sum = a + b;
let range = 0..10;
let result = x * (y + z);
```
