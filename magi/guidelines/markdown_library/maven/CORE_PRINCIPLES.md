# Core Principles

These guidelines define a strict, readable, and consistent format for all Maven projects, optimizing for:

- **Maintainability**: Clear project structure and dependency management.
- **Reproducibility**: Consistent builds across environments and time.
- **Performance**: Optimized build times and minimal overhead.
- **Clarity**: Self-explanatory configuration through proper naming and organization.

### Primary Rule: Convention Over Configuration

Follow Maven conventions strictly. Deviate only when absolutely necessary, and document deviations clearly.
