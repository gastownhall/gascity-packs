# Style Summary

| Element | Required Style |
|:--------|:---------------|
| **Hooks** | Extend `Abstract*ModuleHook`; never implement raw interfaces |
| **Scopes** | `G` Gateway, `D` Designer, `C` Client; `CD` for Vision shared; `GCD` only for cross-scope contracts |
| **Hot-restart** | `setup`/`startup`/`shutdown` may run multiple times per Gateway lifetime; release every resource |
| **Lifecycle order** | `setup` reads schema only; `startup` registers and starts; `shutdown` unregisters everything |
| **EDT** | No blocking work on the EDT — `SwingWorker` for Designer-side I/O |
| **module.xml** | Generated by build plugin; reverse-DNS ID; semantic version; one hook per scope |
| **PersistentRecord** | `RecordMeta` static; `IdentityField` per record; `EncodedStringField` for secrets (8.3 → `SecretConfig`) |
| **Extension points** | Settings record + profile class + `ExtensionPointType`; register in `getExtensionPoints()` |
| **RPC** | Java serialization; common-scope interface; `Serializable` args with `serialVersionUID`; never call from EDT synchronously |
| **Push notifications** | `sendNotification(scope, moduleId, type, payload)`; listener filters by ID + type |
| **Scripting** | `addScriptModule` in `initializeScriptManager`; `@ScriptFunction` + `@KeywordArgs`; properties file docs |
| **Tag system** | `readAsync`/`writeAsync` with `SecurityContext.emptyContext()` for internal; `SimpleTagProvider` for custom namespaces |
| **OPC UA (8.1)** | `DriverType` / `DeviceType` (REMOVED in 8.3); register via `DriverManager` service consumer |
| **Vision** | `AbstractVision*` base; no-arg constructor; `firePropertyChange` in setters; BeanInfo with category masks |
| **Designer workspaces** | `TabbedResourceWorkspace` + `ResourceEditor`; `UndoManager.add` for undo/redo |
| **Datasinks** | `AbstractDatasourceSink` + custom `HistoryFlavor`; `verifyAndUpdate` schema; `storeHistory` for write |
| **Database** | Try-with-resources `SRConnection`; `runPrepQuery`/`runPrepUpdate`; transactions per connection |
| **Scheduling** | `ExecutionManager.register(owner, name, ...)`; `BasicExecutionEngine` for CPU-bound; `unRegister` in shutdown |
| **Localization** | `BundleUtil.addBundle` in setup; `removeBundle` in shutdown; locale-suffixed properties |
| **Module services** | Marker interface in common; `registerService`/`subscribe`; `notifyServiceReady` in startup |
| **Redundancy** | PersistentRecord auto-replicates; `RuntimeStateProvider` for runtime state (8.3 → `SnapshotStateProvider`) |
| **Signing** | Production: `module-signer.jar` or Gradle `signModule`; HSM via Gradle PKCS#11; never commit keystores |
| **Build** | Gradle `io.ia.sdk.modl` preferred; Maven `ignition-maven-plugin` 1.0.x acceptable (no HSM) |
| **JVM** | Java 11 for 8.1.0–8.1.32; Java 17 for 8.1.33+; `--add-opens`/`--add-exports` for JDK 17 strong encapsulation |
| **Logging** | SLF4J only; no `System.out` or `printStackTrace` |
| **Defense in Depth** | Redundant Gateways + signed modules + script error handling + Designer/runtime parity + backups + historian redundancy + external monitoring |
| **Rule of Three** | Failover requires majority agreement (primary + backup + external witness) before promoting |
