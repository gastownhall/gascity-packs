# Select applicable PStack principles

Read `principles/manifest.toml`. Select only principles whose trigger matches
this change. Record each selected principle, trigger, decision, effect,
enforcement, required_artifacts, and evidence in
`pstack.principle-application.v1`. Use only the declared enforcement values:
`artifact`, `check`, `expansion`, `graph-invariant`, or `review`. Do not load
every skill into every worker.

This runtime asset is executed by the Gas City graph.
