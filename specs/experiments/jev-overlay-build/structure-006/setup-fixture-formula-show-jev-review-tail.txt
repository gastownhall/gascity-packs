Formula: jev-review-tail
Description: Gated review tail bonded by the jev-build review gate (one instance per gate item).

Review lanes run only when the gate item says `run`. Synthesis runs only when at
least two lanes run, and the whole review loop is dropped when no lane runs. A
script step then writes the gc.build.review.v1 report and labels the gate's
decisions from the lane verdicts; finalize and publish follow. Nothing is
inherited into a bond, so the review, finalize and publish contracts are
restated here.


Variables:
  {{acceptance}}: run or skip the acceptance lane. (default=run)
  {{acceptance_scope}}: Criterion ids the acceptance lane must review, or all. (default=all)
  {{forwarded_smells}}: Smells Jev confirmed; they go straight to the fix lane. (default=none)
  {{gate}}: How the gate decided: jev, escalate:<reason> or fail-open:<reason>. (default=fail-open:unknown)
  {{implementation_target}}: Role target used to apply review findings. (default=gc.implementation-worker)
  {{loop}}: run or skip the whole review loop (skipped when no lane runs). (default=run)
  {{simplicity}}: run or skip the simplicity lane. (default=run)
  {{simplicity_scope}}: full (smell and design checks) or design (the smell screen was clean). (default=full)
  {{synth}}: run or skip synthesis (skipped when at most one lane runs). (default=run)
  {{test_evidence}}: run or skip the test-evidence lane. (default=run)
