## Why

Formulas omit `gc.provider_panel`. Host sling is the next operator unit.
Panel stamp waits on a compiler this pack cannot land. Those facts live in
docs. Tests can drop host sling from the program and still pass. Tests never
grep `gascity/` for `provider_panel`. Target cook Gherkin can look like a
stamp trigger.

## What Changes

- Record remaining units as live Gherkin.
- Fail closed if the program drops host sling.
- Fail closed if formulas stamp panel keys.
- Fail closed if `gascity/` grows a `provider_panel` consumer in this tree.
- Do not stamp formulas.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `pstack-delivery-evidence`: Remaining units are host sling, restamp after
  receipts, then panel stamp after an out-of-tree compiler.

## Impact

`docs/pstack-program-plan.md` strings stay. Pack tests grow fail-closed
asserts. Formulas and `registry.toml` stay unstamped.
